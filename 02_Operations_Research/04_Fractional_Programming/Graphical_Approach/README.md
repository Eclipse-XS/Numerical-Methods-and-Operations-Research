# Cluster 02.04.B — Fractional-Linear Programming (2D Graphical Approach)

## 1. Computational Problem
Solving 2-variable fractional linear programs geometrically by evaluating the ratio of linear functions across extreme points of a convex polytope.

## 2. Algorithms & Methods
- **Polytope Reconstruction:** Line-line intersection via linear algebra.
- **Level Curves:** Hyperbolic / rotational level curves passing through optimal extreme vertices.
